# 🛒 Superstore Data Analysis – Python Visualization Project

This project performs a detailed exploratory data analysis on sales data from a Superstore. Using Python libraries such as **Pandas** and **Matplotlib**, the project uncovers patterns in sales performance across time, cities, product categories, and profitability trends.

---

## 📁 Project Structure

- `superstore_data_analysis.ipynb` – Jupyter Notebook containing complete analysis, plots, and insights  
- `README.md` – Project documentation

---

## 🧰 Tools & Libraries Used

- Python 3
- Jupyter Notebook
- Pandas
- Matplotlib

---

## 🔍 Key Questions & Analysis

1. **📈 Monthly Sales Trend**  
   - Dual-line plot used to visualize monthly sales volume and revenue trends.
   - Helps identify peak sales months and seasonal patterns.

2. **🏙️ Sales by City & Category**  
   - Total sales compared across different cities and product categories using bar plots.
   - Reveals top-performing regions and categories.

3. **📊 Categorical & Numerical Data Analysis**  
   - Utilized bar plots for categorical variables like product category.
   - Box plots used to visualize distribution and outliers in numerical features like profit and sales.

4. **💰 Profit Analysis**  
   - Line plot shows month-wise profit trends throughout the year.
   - Useful for understanding overall profitability and any loss periods.

---

## 📊 Insights Summary

- Certain cities and product categories consistently contributed more to total sales and profit.
- Monthly sales trends highlighted periods of high performance (e.g., year-end spikes).
- Some product categories showed high sales but lower profit margins, suggesting a need for pricing or inventory strategy review.
- Profit trends revealed both profitable and loss-making months, helping isolate potential issues in cost management or discounts.

## 🚀 How to Run

1. Clone or download the repository.

3. Run all cells to generate the graphs and view insights.
